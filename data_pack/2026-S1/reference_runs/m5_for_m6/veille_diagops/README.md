# Passage de relais réglementaire M5 vers M6

Ce dossier est un état de continuité pédagogique. Il ne constitue pas un avis
juridique. Chaque entrée M6 doit être datée, sourcée auprès de textes officiels
ou d'autorités compétentes et reliée à un contrôle vérifiable : politique
d'exécution, qualification du feedback, trace ou gate de promotion.
